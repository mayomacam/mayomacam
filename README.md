## 🔐 Featured Projects

### 🛡️ **Wazuh SIEM - Enterprise Deployment & Hardening**
Security-hardened SIEM architecture designed for 50–75 endpoints with:
- TLS/mTLS-secured communication (Manager ↔ Indexer ↔ Agents)
- Custom detection rules and correlation logic
- Filebeat authentication & log pipeline optimization
- Deployment automation and scalability considerations

### 🔍 **Custom Rule & Log Analyzer**
Intelligent log analysis framework featuring:
- XML → SQLite conversion for complex SIEM logs
- Dynamic schema generation for unknown/evolving log formats
- Detection rule grouping and enrichment
- Pattern analysis for security event correlation

### ⚔️ **Offensive Security & CTF Solutions**
Hands-on exploitation and challenge writeups:
- Web vulnerabilities (XSS, SSRF, auth bypass, logic flaws)
- Binary exploitation and reverse engineering
- Challenge walkthroughs and methodology documentation
